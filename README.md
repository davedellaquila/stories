# Stories

Long-form stories by Dave Dell'Aquila, published on GitHub Pages:
https://davedellaquila.github.io/stories/

## Structure
- `index.html` — the collection's front page: one card per story, newest first.
- `<story-slug>/index.html` — each story is a self-contained page in its own folder.
  Every story page carries a small "← All Stories" pill (top-left) linking back to `../`.

## Adding a story
1. Create `<story-slug>/index.html` (self-contained; images inlined or in the folder).
2. Add the "← All Stories" pill right after the `<body>` tag.
3. Add a card for it at the top of the story list in `index.html`.
4. Commit and push to `main`; GitHub Pages serves from the repo root.
